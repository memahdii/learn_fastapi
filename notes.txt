14- Table:
    it represents a subject or event in as app
    the table is made up of columns and rows...
    each column: represents a different attribute
    each row: represents a different entry in the table

    primary key: is a column or group of columns that uniquely identifies
        each row in a table
        - tables can have one and only one pk

    unique constraints: it can be applied to any column to make sure every
        record has a unique value for that column

    null constraints: use NOT NULL constraint to ensure the column never left blank
